# OOP Interview Guide (C# / .NET)

An interactive study guide to the four pillars of Object-Oriented Programming, with C# examples.

- **English:** `index.html` — uses the **A PIE** mnemonic (Abstraction, Polymorphism, Inheritance, Encapsulation) and includes model interview answers.
- **Español:** `es/index.html` — usa la regla **HEPA** (Herencia, Encapsulamiento, Polimorfismo, Abstracción).

## What's inside
- Class vs object, explained with a blueprint analogy
- Each pillar: analogy, quick test, C# code, common mistake and a ready-to-say interview answer
- UML diagram showing all four pillars working together
- Commonly confused pairs (interface vs abstract class, overloading vs overriding, composition vs inheritance)
- Flashcards, a "Which pillar is it?" drill and a mini quiz
- 3 coding challenges with solutions
- A spaced-review plan and a mastery checklist

## View it
Open `index.html` in any browser, or visit the GitHub Pages site for this repo.

No build step and no dependencies. Plain HTML, CSS and JavaScript (fonts from Google Fonts).
